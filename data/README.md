> 规则（ai-tool-project-sprint 阶段 1）：每份数据登记来源与许可；规范条目挂出处 + status（`verified`/`pending`/`input_required`）；程序化自制带真值数据是核心资产（固定输入可复现）。`_private/` 目录不入仓。

## 四、合成数据纪律

- **假专利与假主体白名单**：合成专利统一使用虚构专利号（保留测试号段 `99000000…SYN`）与虚构名称（如"一种示例装置（合成）"）；合成申请人/专利权人使用虚构名称（如"示例科技（合成）有限公司""示例个人 A"）＋虚构统一社会信用代码（测试号段 `90000000…SYN`）。**不得使用任何真实专利号、真实申请人、真实代理机构或真实缴费记录。**（守门测试 `test_truth_portfolio_uses_synthetic_number_ranges`）
- **植入真值**：合成专利组合由 `tools/gen_synthetic.py` 生成时同时产出**期望年费金额、期望滞纳金、期望费减资格与减免额、期望到期日**，真值随组合入库；引擎以独立实现路径对账。
- **算例覆盖（M1 实际生成 46 条）**：三种专利类型各自的**每档首末年**阶梯边界（30 条）；**滞纳金档案**（逾期 1/2/6 月 + 7 月超上限降级，4 条）；**费减边界档案**（个人月均收入恰好 5000 元、企业应纳税所得额恰好 100 万元、共同主体数 1/2、跨 2019-07-01 锚点两套阈值，9 条）；**多政策择一档案**（开放许可 15% 与费减 85%/70% 并存择最优惠，3 条）。
- **误报对照集**：真值库 `controls` 段显式声明"应零命中"的干净档案（按期缴费、金额正确、未超滞纳期）与"应降级"的档案（超 `late.grace_months` → 只报 `late_exceeds_cap`，是 `warning` 不是 `fail`）；基准层只读该声明，不自行挑选对照档案。
- **费率表复核纪律**：费率表为**逐年可能调整**的官方公示，规则包每条费率必须挂该页核对痕迹；基准日 2026-10-14 复核时未见 2024-08-06（594 号）之后的调整公告（gov.cn 政策库检索确认），按现行表入库并在台账标注"以入库日费率表为准"。
- **生成确定性**：自研 splitmix64 RNG（sha256 派生固定 seed）、无时间戳（`generated_at=1970-01-01T00:00:00Z`）、无 set 迭代序依赖、禁 stdlib `random`；产物 LF 无 CR；**再生成逐字节一致**（守门测试 + `--check` 双保险）。
- 生成器为**唯一写入者**：产物禁手改；再生成须逐字节一致（守门测试）。

## 五、M1 状态与 M2 起手式

**M1 已建立的数据资产（2026-10-14）**

- `data/knowledge/raw/`：**8 份**官方原文快照（原 4 份 + 实施细则 769 号、专利法 2020、审查指南 78/84 号令）+ `_ledger.json`（逐份 sha256，复抓一致）；

- `data/truth/`：合成组合（18 件虚构专利 × 6 主体 + 缴费记录）+ 真值库（46 条算例 + 误报对照集），**位级可复现**；
- CLI：`patfee rules diff <id>`（316 号阈值前后对照 + 594 号新增项目与同口径互证）。

**M2 待办（计算引擎）**

1. `calc/late.py` 滞纳金引擎：逐月累加（5%/月）、上限 6 个月、自然月口径（`late.month_basis` 承载，代码不写死）；超上限走 `late_exceeds_cap`（warning）；
2. `calc/reduction.py` 费减判定：阈值严格小于、比例取决于共同与否、跨 2019-07-01 锚点选版、594 号多政策择最优惠不叠加；
3. 基准 B2/B3 实装（真值库对账 + 规则驱动端点枚举两层），B4 留 M3；
4. CLI `patfee reduction <主体.json>` 子命令。
