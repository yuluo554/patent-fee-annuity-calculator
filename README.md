# patent-fee-annuity-calculator

专利年费与费减合规计算工作台 —— 以国家知识产权局**现行专利收费标准表**与**《专利收费减缴办法》财税〔2016〕78 号 + 公告第 316 号 + 公告第 594 号**为规则源，把**年费阶梯计算 + 滞纳金与恢复权利 + 费减资格判定与减免额 + 专利组合批量排期 + 报告导出**做成**逐项挂政策依据、可复现、留指纹**的本地工具（桌面 exe + CLI 双形态）。

> 本地目录 `10-14-patent-fee-annuity-calculator`（`10-14` = 2026-10-14 日期标签）。GitHub 仓库名发布时用纯净名 `patent-fee-annuity-calculator`，见 [plan/00-README总览.md](plan/00-README总览.md)。

**全本地处理、零上传**：专利组合台账含专利权人与代理信息，工具默认不联网、不做任何数据外发。

> 状态：⬜ **v1 题目定稿（2026-10-14），待开发**——计划文档见 [plan/](plan/)，开发从 M1（数据先行）开始。

## 它解决什么问题

| 痛点 | 本工具的能力 |
|---|---|
| 这件专利今年该缴多少年费？ | 按专利类型 × 年度区间阶梯确定性计算，输出所处区间与费率依据 |
| 逾期了滞纳金怎么算？ | 逐月累加（每超期 1 个月加收当年全额年费 5%），跨月可溯 |
| 我够不够格申请费减？减多少？ | 费减资格判定（公告第 316 号阈值）+ 减缴比例（单主体 85% / 共同主体 70%） |
| 同时能享受多项减免时怎么选？ | 多政策择一判定（择最优惠、不得重复享受，依公告第 594 号） |
| 组合几十上百件，哪件快到期？ | 批量排期 + 到期预警清单（按期限升序） |
| 缴费是循环的，"这轮比上轮清了没" | 跨年对账：新增到期 / 已缴清 / 持续未缴 |
| 结论要能交给内部/客户/存档 | 报告导出（Markdown + XLSX）+ 组合 sha256 指纹 |

## 规则库版本化与 status 门控（本项目的核心纪律）

规则库按 **`依据文件 × 版本`** 组织（`data/rules/`），费率与费减规则编码为可执行规则（JSON）。每条挂文号/费率表项目与 `status`：

- `verified` —— 已逐项挂原文或官方费率表核对，**可进入计算路径**；
- `pending` —— 待核对，**绝不参与任何计算或判定**。

**未挂原文核对的条目不得落库生效**。按年度锚定规则版本（2019-07-01 前后、2024-08-06 前后分别适用对应政策）。

## 依据锚点（基准日 2026-10-14 核验）

| 依据 | 编号 | 状态 |
|---|---|---|
| 专利收费减缴办法 | **财税〔2016〕78 号** | ✅ **自 2016-09-01 施行**；✅ 减缴比例 单主体 **85%** / 共同主体 **70%**（原文核对；**非**"个人 85%、企业 70%"） |
| 调整专利收费减缴条件的公告 | **知识产权局公告第 316 号** | ✅ 2019-06-28 发布、**自 2019-07-01 起**；个人年收入 **4.2 万→6 万**、企业应纳税所得额 **30 万→100 万** |
| 调整部分专利收费标准和减缴政策的公告 | **知识产权局公告第 594 号** | ✅ 2024-08-06；期限补偿请求费 **200 元/件**、补偿期年费 **8000 元/年**、开放许可年费减免 **15%** |
| 现行专利收费标准表 | 国家知识产权局公示 | ✅ 已直连获取（年费阶梯、滞纳金 5%/月、优先权要求费 80 元等）；入库时逐项复核 |

> **基准日核验**：截至 2026-10-14 未见新的费率表换版或费减政策替代/作废/延期公告（594 号后的调整未检出）；政策为多文号叠加（2016/2019/2024），历史年度回算需求真实。

## 快速开始（M1 后可用）

要求 Python 3.8+（核心功能无第三方依赖）。

```bash
python -m venv .venv
# Windows(Git Bash): source .venv/Scripts/activate    Linux/macOS: source .venv/bin/activate
python -m pip install -U pip
python -m pip install -e ".[dev]"
```

```bash
patfee selfcheck               # 数据目录定位 + 规则库加载 + status 门控计数
patfee calc <专利.json>        # 单件年费/滞纳金计算（人类可读 / --json）
patfee reduction <主体.json>   # 费减资格与减免额判定
patfee scan ./组合目录 --out ./report-out   # 组合批量排期 + 报告导出
patfee bench                   # 内置评测基准
patfee version
```

## 限制与免责

- **首期范围**：现行专利收费标准表（三类专利年费阶梯 + 滞纳金 + 恢复权利/评价报告/期限补偿）+ 费减政策（78 号 + 316 号 + 594 号）；商标/著作权费用留扩展。
- 本工具输出为**基于官方费率表与政策文本的费用测算**，不构成法律或代理意见；正式缴费金额以国家知识产权局规定与缴费通知为准。
- 规则条目核对状态以规则库 `status` 为准；**`pending` 条目不参与计算**。
- 费率表可能逐年调整，规则包每条费率挂该页核对痕迹。
- 演示与基准一律使用**合成专利组合**，不含任何真实专利或申请人信息。
