# 10-14-patent-fee-annuity-calculator 项目计划总览

**项目**：专利年费与费减合规计算工作台（知识产权费用管理工具，Windows 桌面 + CLI 双形态，官费费率表规则化 + 年费阶梯/滞纳金 + 费减资格判定 + 组合批量排期 + 报告导出）
**方法论**：ai-tool-project-sprint（政策条款库 + 版本化费率与政策规则集 + 合成组合真值基准 + 证据指纹 + 离线交付）
**项目系列**：同系列第 19 题（前作名称与业务领域按脱敏纪律不入公开仓，见「决策记录」品牌隔离项）
**命名约定**：本地目录 `10-14-patent-fee-annuity-calculator`（`10-14`=2026-10-14 日期标签）；**GitHub 仓库名 = `patent-fee-annuity-calculator`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`（LICENSE/pyproject 一致）。
**定位宣言（v1）**：把"这件专利今年该缴多少 → 逾期滞纳金怎么算 → 够不够格费减、减多少 → 整个组合未来几年花多少、哪件快逾期"整条链做成**费率表规则化、逐项挂政策依据、可批量排期**的本地工作台——LLM 聊天给不了持久费率表、阶梯年费的逐段可溯计算与整组合批量对账，本工具是专利费用管理与申报减缴前的口径防线。
