# 05 数据计划与里程碑（含 M0 DoD）

## 一、数据计划

### 1.1 三类数据

| 类 | 目录 | 生成者 | 性质 |
|---|---|---|---|
| 规则包 | `data/rules/` | `tools/gen_rulesets.py` | 冻结产物，**禁手改**；`status` 门控 |
| 依据索引 + 原文快照 | `data/knowledge/`（`clauses.json` + `raw/`） | 抓取脚本 + 手工登记 | 索引入仓；**`raw/` 原文快照不入包**（版权 + 体积） |
| 合成组合与真值 | `data/truth/` | `tools/gen_synthetic.py` | 冻结产物；**零真实信息** |

**生成器是唯一写入者**。改体例/加条目一律走生成器整目录重生成，配"再生成逐字节一致"守门测试。

### 1.2 规则包入库策略（M1 的核心工作）

1. **逐项复核**：对每一条费率/阈值，回到 `cponline.cnipa.gov.cn` 费率表页或政策原文页，逐字核对后把 `status` 由 `pending` 改为 `verified`，并在 `basis.note` 写明复核结论（含页码/条目定位）。
2. **上位法补齐**：《专利法》《实施细则》《审查指南》入库前先定位现行版本与施行日期（基准日实测 gov.cn 直链 404 → 走 flk.npc.gov.cn 检索接口或 gov.cn 政策库）。**未定位到的条目保持 `pending`**，不阻断其他条目。
3. **按年度锚定**：`anchor_from`/`anchor_to` 决定该规则集在哪个时间窗内适用；`calc` 时按**缴费年度的年月**选集。
4. **差异报告**：`rules diff` 输出 316 号前后阈值对照（个人年 4.2 万→6 万、企业 30 万→100 万）与 594 号新增项目/减免。

### 1.3 合成数据纪律（摘要，详见 [data/README.md](../data/README.md) §四）

- 专利号测试号段 `99000000…SYN`；统一社会信用代码 `90000000…SYN`；主体名带"（合成）"；
- 植入真值：期望年费 / 期望滞纳金 / 期望费减资格与减免额 / 期望到期日，随组合入库；
- 误报对照集：显式声明"应零命中"的干净件（按期缴费、金额正确）与"应降级"的件（`warning` 而非 `fail`）；
- RNG 自研确定性（splitmix64），**禁 stdlib `random`、禁 set 迭代序、禁系统时钟**；
- **算例覆盖**：三类专利各设算例；阶梯边界档案（第 3/4 年之间、各档首末年度）；滞纳金档案（逾期 1/2/6 月）；费减边界档案（月均收入恰好 5000 / 应纳税所得额恰好 100 万 / 共同主体数 1 与 2）；多政策择一档案（开放许可 15% 与费减 85% 并存）。

### 1.4 依据查证记录

见 [data/README.md](../data/README.md) §二（逐条 ✅/⬜ + 渠道）。**基准日 2026-10-14**。查证失败按"待核对"降级继续，不空转、不编造。
