# 04 模块详设

## 一、规则包（ruleset）Schema

### 1.1 目录结构

```
data/rules/
├── manifest.json                    # 规则集索引 + 门控门槛 + 禁用 token 表
├── fee_schedule.v2016.json          # 专利收费标准表（费率表）
├── reduction_78.v1.json             # 财税〔2016〕78 号（减缴比例与减缴项目）
├── reduction_316.v1.json            # 公告第 316 号（阈值调整）
└── reduction_594.v1.json            # 公告第 594 号（新增收费项目与减免）
```

组织键 = **`依据文件 × 版本`**。每份文件独立成集，不相混。

### 1.4 `status` 三态（门控语义）

| status | 含义 | 门控行为 |
|---|---|---|
| `verified` | 已逐项挂原文/官方费率表核对 | 允许进计算路径 |
| `pending` | 待核对（含仅锚点级核对） | **拒绝进计算路径**；`--preview` 可预览但退出码为 1 |
| `input_required` | **本不由规则包承载**的外部输入（随工况而异的系数） | 放行门控，但运行时**必须显式索取**，缺失即 exit 2 —— **绝不静默取 0/1** |

判别口诀：**"未核对"(`pending`) 与"本不由规则包承载"(`input_required`) 是两回事** —— 前者拦门，后者放行但运行时必索。

### 1.5 零政策字面量门禁

- **禁用 token 来源**：生成器从全部 ruleset 条目值推导 —— 所有**绝对值 ≥ 100 的整数**（含费率表小值 `80`/`50` 的显式补录）+ **所有非精度约定的小数**（`0.05`/`0.85`/`0.70`/`0.15`）+ **百分号字符串**（`5%`/`85%`/`70%`/`15%`）。
- **豁免口径（写死，避免门禁刷屏）**：`abs(n) < 100` 的整数 = 日历常数 / 年度档边界 / 数组长度 / 精度约定；小数 `0.01`/`0.1`/`0.5`/`1`/`2` = 精度与半量换算约定。豁免表存于 `src/patfee/rules/literals.py` 并在 `data/rules/manifest.json` 中镜像登记（两处一致由测试守门）。
- **扫描面**：`src/patfee/**/*.py`（**含 docstring 与注释**）、`tools/` 下的报告/审计脚本、将来的 GUI 前端源码。**生成器 `tools/gen_rulesets.py` / `gen_synthetic.py` 不在扫描面内**（它们是规则值的唯一写入者与来源）。
- **`tests/` 为何不在扫描面内**：测试必须**写明**期望的政策数值（如"第 4-6 年应为 1200.00 元"）才能验证规则包与引擎一致——这是对**单一来源的核对**，不是第二份真相。判别口诀：**"这个数字是被计算的，还是被断言的？"** 被计算 → 必须来自规则包；被断言 → 正是门禁要守护的对象。故门禁扫**生产代码**，测试责在**验证**规则值。
- **词边界**：整数 token 用 `(?<![0-9])…(?![0-9])` 匹配；小数按原样匹配。
- **行内放行**：`# literal-ok: <理由>` 使该行免疫；放行项**仍打印在报告中**（可审计"为什么放过"），不静默吞。
- **可证伪**：`patfee selfcheck` 内跑门禁 `--selftest` 阳性对照（在内存副本里注入一个禁用 token，断言门禁报红）。**门禁自身若全绿但 token 集为空 → 报配置错误**（防"门禁什么都没查"）。

### 1.6 生成器纪律

- `tools/gen_rulesets.py` 是 `data/rules/` 的**唯一写入者**；产物**禁手改**。
- 落盘 `json.dumps(..., ensure_ascii=False, indent=2, sort_keys=False)` + `write_bytes`（LF）→ 两次运行**逐字节一致**。
- `--check` 模式：重生成到内存 → 与磁盘逐字节比对 → 一致打印 `FROZEN_RULESETS_OK`、不一致非零退出。**这是"改完还自洽"的统一证据**。
- 无时间戳、无 dict 迭代序依赖、无 `random`。

## 二、领域模型（`domain/models.py`）

```python
class PatentType(str, Enum):
    INVENTION = "invention"          # 发明
    UTILITY_MODEL = "utility_model"  # 实用新型
    DESIGN = "design"                # 外观设计
    DESIGN_INTL = "design_intl"      # 外观设计国际注册

@dataclass(frozen=True)
class FeeBasis:
    doc_no: str        # 政策/费率表文号
    clause: str        # 条款/费率表项目
    url: str
    retrieved: str
    ruleset_id: str
    ruleset_version: str
    entry_key: str

@dataclass(frozen=True)
class AnnuityResult:
    patent_type: PatentType
    year: int                 # 缴费年度（第 N 年度）
    amount: Decimal           # 应缴年费（元，两位小数）
    tier: Tier                # 所处区间（from_year/to_year/label）
    basis: FeeBasis
    reasons: tuple[ReasonCode, ...] = ()
    warnings: tuple[str, ...] = ()
```

**金额字段类型必须是 `Decimal`**；`__post_init__` 断言拒收 float（`isinstance(x, float)` 即抛 `TypeError`）。

## 三、年费阶梯计算（`calc/annuity.py`）

### 3.1 年度推导

专利年度自**申请日**起算：第 N 年度 = `申请日 + (N-1) 年` 至 `申请日 + N 年` 区间。
- `derive_annuity_year(applied_on, paid_on)` → N（用于组合排期时按当前日期/给定日期算"当前处在第几年度"）；
- 显式指定 `year` 时以指定值为准（历史年度回算场景）。

### 3.2 档位查找（边界显式）

```python
def find_tier(ladder, year) -> Tier:
    # 区间取 [from_year, to_year] 双闭；边界由规则包数据决定，代码内不出现档位数字
    for tier in ladder:
        if tier.from_year <= year <= tier.to_year:
            return tier
    raise OutOfRange(...)   # 原因码 out_of_range（非异常崩，走 ReasonCode）
```

**边界语义**：第 3 年属第 1 档、第 4 年属第 2 档（**恰好跳档年归新档**）。该语义由规则包 `from_year/to_year` 双闭区间表达 + 基准枚举验证，**不在代码里写死 3/4/6/9**。

### 3.3 计算流

```
输入 → 校验专利类型 → 门控(scope=calc) → 取 ladder → find_tier → amount = tier.amount
     → quantize(0.01, HALF_UP) → 组装 FeeBasis + 免责声明
```
门控失败 → `AnnuityResult.amount = None` + `reasons=(gated_pending,)` + 退出码 1（`--preview` 时仍填金额但退出码 1）。

## 四、滞纳金与恢复权利（`calc/late.py`，M2）

- 输入：应缴年费全额、规定缴费期限、实际缴费日；
- `overdue_months = ceil(逾期天数 / 30)`? **否** —— 月数口径按规则包 `late.month_basis`（`calendar_month` / `thirty_day`），**不写死在代码里**；M1 核对实施细则后定；
- `surcharge = full_annuity * monthly_rate * months`，跨月累加；
- 宽限期与上限（进入失效流程的时点）由规则包 `late.grace_months` / `late.cap_months` 承载；超过上限 → `late_exceeds_cap`（**风险提示 ≠ 法律判定**）；
- 恢复权利请求费、专利权评价报告请求费按费率表条目计入。

## 五、费减资格判定（`calc/reduction.py`，M2）

### 5.1 输入

```json
{
  "as_of_year": 2026,
  "applicants": [
    {"kind": "individual", "annual_income": "58000", "monthly_avg_income": "4833.33"},
    {"kind": "entity", "taxable_income": "980000"}
  ],
  "open_license": false,
  "compensation_period_year": false
}
```

### 5.2 判定流

1. **按年度锚定规则版本**：取 `as_of_year` 的年月 → 定位 316 号锚点（`2019-07-01`）前后的阈值条目；594 号锚点（`2024-08-06`）决定 15%/8000/200 是否适用；
2. **主体构成**：`n = len(applicants)`；`n == 1` → 单主体；`n >= 2` → 共同主体；
3. **资格判定**（逐主体，全部满足才通过）：
   - 个人：上年度月均收入 **低于** 阈值（月均 `< 5000`）或年收入低于 `60000`；
   - 单位：上年度应纳税所得额 **低于** `1000000`；
   - **恰好等于阈值 → 不满足**（"低于"是严格小于，边界主体入基准）；
4. **减缴比例**：单主体 `0.85` / 共同主体 `0.70`（取自 `reduction_78` 规则条目，**代码内不出现这两个数**）；
5. **多政策择一（594 号）**：候选减免 = { 费减比例, 开放许可 15% } 等；取**减免额最大**者；`chosen` 与 `candidates[]` 全部留痕，输出 `no_double_benefit: true` 说明**未叠加**；
6. 减免后应缴额 = `full * (1 - rate)`，`quantize(0.01, HALF_UP)`。

### 5.3 输出

```json
{
  "eligible": true,
  "applicant_count": 2,
  "combined": true,
  "reduction_rate": "0.70",
  "thresholds": {"individual_annual_income": "60000", "entity_taxable_income": "1000000"},
  "anchors": {"threshold_policy": "公告第316号", "anchor_from": "2019-07-01"},
  "candidates": [{"policy": "费减", "rate": "0.70", "amount": "..."},
                 {"policy": "开放许可年费减免", "rate": "0.15", "amount": "..."}],
  "chosen": {"policy": "费减", "rate": "0.70"},
  "no_double_benefit": true,
  "bases": [ ... ]
}
```

## 六、组合批量排期与对账（`calc/portfolio.py`，M3）

- **输入**：`--in <目录/*.json>` 或清单文件；每件 = 合成组合条目（主体 + 专利 + 缴费记录）；
- **失败隔离**：单件异常 → `{"id": ..., "kind": "failed", "reason": "bad_format"}`，继续。
- **失败件不改变退出码**（退出码由"是否检出问题"决定）。
- **跨轮对账三集合**：
  - 配对主键 = **稳定身份键** `patent_no`（**不是内容指纹**）；
  - `new_due`（新增到期）/ `settled`（已缴清）/ `still_unpaid`（持续未缴）；
  - 辅助集：`content_changed`（身份在但金额/期限变了）、`vanished`（上轮有本轮无）。
  - 内容指纹变化**另立标记**，不让它退化成"新增 + 移除"。
- **到期预警**：按 `due_date - today` 升序输出"未来 N 个月内到期清单"。
- **对账口径单一实现源**：`benchmark/cases.py` 的 `compare_rounds()` 供 CLI 与基准共用。

## 七、证据链与报告（`report/`，M3/M5）

- **单一渲染源**：`report_sections(result)` 返回结构化章节列表（`Section(title, rows)`），Markdown 渲染器与 XLSX 渲染器各自消费它 → "两格式内容一致"成为**结构性质**而非人工比对。
- **报告必须包含四块**（有测试守门）：
  1. 输入事实（合成组合条目/主体信息）；
  2. **参数来源块**（每项参数：发布机关 + 适用年度 + 文号 + URL + 抓取日期）——让"只拿到报告、没有仓库"的读者也能核证；
  3. 逐项计算过程（**直接渲染引擎 `steps` 留痕，报告层不重算**）；
  4. 适用依据 + 免责声明。
- **未启用章节显式写出**："本次导出未启用滞纳金计算（用 `--with-late` 启用）"，不留空 —— **"没查"与"查了没问题"是两种结论**。
- **无外链**（机读产物断网可开）：XLSX 单元格与关系项不得含 URL；URL 只落**文本列**。硬断言测试。
- **指纹**：每件挂 `content_sha256`；报告产物自身挂 sha256 进 `evidence.json`。**报告逐字节可复现**（两次导出 sha256 一致，实测背书）：XLSX 的 zip 条目时间戳 + 文档属性时间戳全部固定（`ZIP_STORED` / 固定 `date_time` / `create_system=0`），或走自写最小 OOXML writer。

## 八、基准（`benchmark/`，M0 起）

| 套件 | 内容 | M0 状态 |
|---|---|---|
| `B1 ladder` | 阶梯边界：各档首末年度 + 恰好跳档年，**样本驱动 + 规则驱动两层** | 骨架（规则驱动，读 fixture 规则表推导端点） |
| `B2 late` | 跨月累加 + 上限边界枚举 | 占位（M2） |
| `B3 reduction` | 收入恰好阈值 / 所得额恰好阈值 / 共同主体数 1&2 | 占位（M2） |
| `B4 portfolio` | 合成组合植入真值全量重算对账 | 占位（M3） |

- 退出码三语义：`0` 达标 / `1` 未达标或门控拦截 / `2` 用法或坐标错误（**未知套件名必须 exit 2**，不许静默跳过）。
- `--only <套件>` 白名单注册；部分运行时不判定未测指标。
- **每套件配探活（可证伪）测试**：注入缺陷（坏引用/期望篡改）→ 断言该套件必须报未达标。防"基准全绿其实什么都没查"。
- 门槛取自 manifest；**分母不能悄悄做小** —— `notes` 如实写"该类用例未生成"。

## 九、CLI 与编排（`cli.py` / `calc/pipeline.py`）

- `pipeline.compute_annuity(request) -> AnnuityResult`、`pipeline.compute_reduction(...)`、`pipeline.scan_portfolio(...)`：**唯一编排入口**，CLI 与 GUI 共用。
- 展示名、单位、四舍五入口径全部上收编排层（`domain/labels.py`），表现层零判定逻辑。
- CLI 只做：解析参数 → 调 pipeline → 渲染（人类可读 / `--json`）→ 映射退出码。
- **入口 UTF-8 守卫**：`console.ensure_utf8_stdio()` 按 `stream.encoding` 探针决定是否 `reconfigure`（zh-CN cp936 保持不动，cp1252 等才改）；`tools/` 下每个会打印的脚本**同样调用**（漏守 tools 脚本是 CI 首跑全红的常见根因）。
- `--json` 输出走紧凑确定性序列化（`ensure_ascii=False`、`sort_keys=True`）。

## 十、桌面界面（`gui/`，M5）

- PySide6 多页签；**只消费 `pipeline` 公开函数**，零判定逻辑。
- **AST 静态门禁三条齐上**：① 不 import 规则层/领域层内部模块；② 无算术 `BinOp`（`* / - // % **` 且两侧操作数非纯字符串字面量）；③ 无政策数值字面量（同一份 `BANNED_TOKENS`）。
- offscreen 测试常驻（`QT_QPA_PLATFORM=offscreen` 必须在首次 import PySide6 **前**设置）；模态框全部屏蔽；中文字体按 `WINDIR` 推导路径显式 `addApplicationFont`（不写死盘符）。
- `patfee gui` **惰性导入**，`try` 包住**从 import 到调用完成**整段，缺依赖 exit 3（提示按冻结态分流）。

## 十一、打包（M5/M6）
- PyInstaller **onedir 双 exe**：GUI（`console=False`）+ CLI（`console=True`），两者同一 `main`。
